# ⚡ EnerGrid – Campus Energy Analyser

**EnerGrid** is a C++-based Campus Energy Monitoring and Management System designed to monitor energy consumption, manage electrical resources, identify faults, and simplify maintenance activities within a campus environment.

The project demonstrates the practical application of Object-Oriented Programming, Data Structures, and file handling in C++.

## 🎯 Objectives

- Monitor campus energy consumption.
- Manage and control energy usage across different buildings.
- Detect overload conditions and generate alerts.
- Track maintenance requests and prioritize repair work.
- Generate energy usage reports.
- Provide role-based access for different users.
- Store and retrieve campus data using file handling.

## 🚀 Key Features

### 1. Dashboard
- Displays an overview of campus energy information.
- Provides access to different system modules.

### 2. Energy Control
- Manages energy-related information for campus buildings.
- Supports monitoring and controlling energy usage.

### 3. Live Monitoring
- Simulates live energy readings.
- Identifies sustained overload conditions.
- Generates alerts based on monitoring conditions.

### 4. Maintenance Management
- Manages maintenance work orders.
- Prioritizes maintenance activities.
- Supports fault tracing through campus connections.

### 5. Reports
- Provides energy-related reports for analysis.

### 6. Settings and User Management
- Supports different user roles.
- Provides account management and access control.
- Stores user information.
